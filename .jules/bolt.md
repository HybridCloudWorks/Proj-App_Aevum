## 2024-06-18 - [Missing Unsubscribe in useEffect Cleanup]
**Learning:** Found an edge case in `DashboardScreen.jsx` where the `useEffect` cleanup function references `unsubFamilies()`, `unsubTasks()`, `unsubMembers()`, and `unsubMemories()`. The inner logic updates `unsubMembers` and `unsubMemories` only if `families.length > 0`. However, since `families` is a dependency, whenever `families` updates, the cleanup function runs, and the previous `unsubMembers` and `unsubMemories` will be executed. This pattern is safe if correctly implemented, but we have multiple subscriptions dependent on a prop that changes over time within a single useEffect. It is better to separate them into distinct useEffect hooks for cleaner dependency management and guaranteed resource cleanup.
**Action:** When subscribing to resources dependent on the result of another subscription, split them into multiple `useEffect` hooks. This ensures clean unsubscription whenever the dependencies change, preventing memory leaks and stale data.
